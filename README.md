# Early personal portfolio

An earlier HTML/CSS portfolio with photography, robotics project descriptions, and contact information. The original content reflects 2023.

For my newer portfolio source, see [myWebsite](https://github.com/CodeOnWheels/myWebsite).

## Run locally

```sh
git clone https://github.com/CodeOnWheels/Portfolio.git
cd Portfolio
python -m http.server 8000
```

Open http://localhost:8000. This is a static site with no package dependencies or build step.

## Structure

- `index.html` — introduction and photography.
- `projects.html` — robotics and a Scratch cipher project.
- `contact.html` — original contact page.
- `styles.css` — shared styling.
- `img/` — image assets.

The project is retained as an early web-development example. Education plans, roles, and social handles in its original pages may be out of date.
